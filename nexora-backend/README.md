# بک‌اند Kartify (فروشگاه اینترنتی)

بک‌اند ساده با **Node.js + Express + MongoDB** برای یک فروشگاه اینترنتی (شبیه سایت Kartify Next، تم مگامارت) با داده‌های نمونه‌ی فارسی. فقط یک نوع کاربر وجود داره: **مشتری** — کسی که میاد خرید می‌کنه. مدیریت محصولات و دسته‌بندی‌ها از طریق فایل seed یا مستقیم از دیتابیس انجام می‌شه (نقش ادمین/فروشنده در بک‌اند وجود نداره).

## امکانات
- ثبت‌نام و ورود مشتری با JWT
- مشاهده و جستجوی محصولات + فیلتر بر اساس دسته‌بندی و قیمت
- ثبت نظر و امتیاز برای محصول
- سبد خرید
- ثبت سفارش از روی سبد خرید و مشاهده سفارش‌های خودم

## پیش‌نیاز
- Node.js نسخه ۱۸ به بالا
- یک دیتابیس MongoDB (لوکال یا رایگان از [MongoDB Atlas](https://www.mongodb.com/atlas))

## نصب و اجرا
```bash
# ۱. نصب پکیج‌ها
npm install

# ۲. کپی فایل env و تنظیم مقادیر
cp .env.example .env
# سپس مقدار MONGO_URI و JWT_SECRET رو داخل .env عوض کن

# ۳. وارد کردن داده‌های نمونه فارسی (محصولات، دسته‌بندی‌ها، دو کاربر تست)
npm run seed

# ۴. اجرای سرور (حالت توسعه با ری‌استارت خودکار)
npm run dev

# یا اجرای عادی
npm start
```

سرور روی آدرس `http://localhost:5000` بالا میاد.

## مدیریت محصولات و دسته‌بندی‌ها
چون نقش ادمین/فروشنده نداریم، برای افزودن یا ویرایش محصولات دو راه داری:
1. فایل `src/seed/seedData.js` رو ویرایش کن (محصول/دسته‌بندی جدید اضافه کن) و دوباره `npm run seed` رو بزن.
2. مستقیم با ابزاری مثل **MongoDB Compass** به دیتابیس وصل شو و رکوردها رو دستی اضافه/ویرایش کن.

## مسیرهای API (Endpoints)

### احراز هویت
| متد | مسیر | دسترسی | توضیح |
|---|---|---|---|
| POST | `/api/auth/register` | عمومی | ثبت‌نام مشتری |
| POST | `/api/auth/login` | عمومی | ورود |
| GET | `/api/auth/me` | خصوصی | اطلاعات کاربر لاگین‌کرده |

### آپلود عکس محصول
| متد | مسیر | دسترسی | توضیح |
|---|---|---|---|
| POST | `/api/upload` | عمومی | آپلود تا ۵ عکس با فیلد فرم `images` (چندتایی، multipart/form-data)، خروجی: آرایه‌ای از لینک‌های عکس |

بعد از آپلود، لینک برگشتی رو (مثلاً `http://localhost:5000/uploads/xxxx.jpg`) توی فیلد `images` محصول داخل `seedData.js` یا مستقیم توی دیتابیس بذار.

### دسته‌بندی‌ها
| متد | مسیر | دسترسی |
|---|---|---|
| GET | `/api/categories` | عمومی |

### محصولات
| متد | مسیر | دسترسی |
|---|---|---|
| GET | `/api/products` | عمومی (فیلتر: `keyword`, `category`, `minPrice`, `maxPrice`, `page`, `limit`) |
| GET | `/api/products/:id` | عمومی |
| POST | `/api/products/:id/reviews` | خصوصی (`{ rating, comment }`) |

### سبد خرید
| متد | مسیر | دسترسی |
|---|---|---|
| GET | `/api/cart` | خصوصی |
| POST | `/api/cart` | خصوصی (`{ productId, quantity }`) |
| PUT | `/api/cart/:itemId` | خصوصی (`{ quantity }`) |
| DELETE | `/api/cart/:itemId` | خصوصی |

### سفارش‌ها
| متد | مسیر | دسترسی |
|---|---|---|
| POST | `/api/orders` | خصوصی (`{ shippingAddress, paymentMethod }`) |
| GET | `/api/orders/my` | خصوصی |
| GET | `/api/orders/:id` | خصوصی |

## احراز هویت در درخواست‌ها
بعد از لاگین، توکن دریافتی رو در هدر بفرست:
```
Authorization: Bearer <token>
```

## مراحل بعدی پیشنهادی
- اتصال درگاه پرداخت واقعی (زرین‌پال) به جای فیلد ساده `paymentMethod`
- آپلود واقعی تصویر محصولات (مثلاً با S3 یا لیارا آبجکت استوریج)
- اتصال به فرانت‌اند Next.js (مثل تم مگامارت که دیدی) از طریق همین APIها
